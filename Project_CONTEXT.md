# Projet PFA

## Titre

Développement d'une application web de gestion et de planification de projets BTP : étude et suivi.

## Objectif

Développer une application web permettant de gérer :

* Les utilisateurs
* Les rôles et permissions
* Les sociétés
* Les clients
* Les projets
* Les documents
* Les devis
* Les factures
* Les paiements
* Le suivi d'avancement des projets
* Les tableaux de bord

## Technologies

Frontend :

* React

Backend :

* Laravel

Base de données :

* MySQL

## Hébergement

o2switch

## Modules principaux

### Authentification

* Connexion
* Déconnexion

### Gestion des utilisateurs

* Création
* Modification
* Suppression
* Attribution des rôles

### Gestion des rôles

* Gestion des permissions

### Gestion des sociétés

* Sociétés publiques
* Sociétés privées

### Gestion des projets

* Création
* Planification
* Suivi
* Avancement

### Gestion documentaire

* Ajout de documents
* Téléchargement
* Archivage

### Gestion commerciale

* Clients
* Devis
* Factures

### Gestion financière

* Paiements
* Dépenses

### Dashboard

* Statistiques
* Indicateurs de performance
